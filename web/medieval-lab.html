main tool

This page needs WebMIDI with SysEx.

Use Chrome or Edge on a desktop (or Chrome on Android). Safari and iOS can’t run it.

This page answers one question: will an EP-1320 boot firmware built for the EP-133 / EP-40? Their firmware is signed with a different key than the Medieval’s, so the likely answer is no — the unit rejects it and falls back to its bootloader. Then this page puts the stock Medieval firmware back automatically.

Before you start, close every other app or browser tab that uses MIDI — TE’s sample tool and updater included. On Windows only one program can hold the port.

1 · connection check

Plug the EP-1320 in over USB-C and turn it on. This step only reads — it changes nothing on the unit.

      3 · probe flash + automatic restore

      What happens: the probe image is flashed with its header set to the Medieval’s SKU. The page waits for the unit to reboot and records what it reports. Unless the probe actually booted, the page then flashes the stock Medieval firmware back and checks the unit is running it again. Samples and projects stay in their own storage and a firmware flash doesn’t touch them. Even so, there’s no backup path for the Medieval yet.
